Hentai API Documentation

This API provides access to scrape content from nhentai and 3hentai websites.

Available Endpoints

1. Search nhentai

Endpoint: GET /snh/

Parameters:

  • q (required): Search query
  • p (optional): Page number (default: 1)
curl -X GET "http://localhost:5000/snh/?q=inuboshi&p=1"
{ "results": [...], "total_pages": 5, "current_page": 1 }

2. Get nhentai data

Endpoint: GET /vnh/

Parameters:

  • code (required): Gallery numeric code
curl -X GET "http://localhost:5000/vnh/?code=23535"

3. Search 3hentai

Endpoint: GET /s3h/

Parameters:

  • q (required): Search query
  • p (optional): Page number (default: 1)
curl -X GET "http://localhost:5000/s3h/?q=inuboshi&p=1"

4. Get 3hentai data

Endpoint: GET /v3h/

Parameters:

  • code (required): Gallery code (can be alphanumeric)
curl -X GET "http://localhost:5000/v3h/?code=357360"

Python Requests Example

import requests response = requests.get("http://localhost:5000/snh/", params={ "q": "inuboshi", "p": 1 }) data = response.json() print(data)
